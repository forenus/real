# 매물 추적기 (동탄역포레너스)

네이버 부동산에서 특정 단지의 **매매 매물**을 평형별로 집계하고,
**날짜별 증감(어제 vs 오늘)** 을 보여주는 도구입니다.

> 매물 개수는 "지금 이 순간" 값만 조회됩니다. 그래서 **갱신을 누른 날부터**
> 데이터가 쌓이고, 다음 날부터 증감(▲▼)이 표시됩니다.

## 실행 방법

```powershell
cd d:\ANTI\real
node server.js
```

브라우저에서 **http://localhost:5173** 접속 → **"오늘 매물 갱신"** 클릭.

- 토큰이나 로그인은 **필요 없습니다.** 프로그램이 내부적으로 브라우저를
  띄워 네이버 데이터를 자동으로 가져옵니다(약 10~20초 소요).

## 매일 사용

매일 한 번 **"오늘 매물 갱신"** 을 누르면 그날 매물 수가 저장되고,
직전 기록과 비교한 증감이 표에 나타납니다.

- 빨강 ▲ : 매물이 늘어남 (매도 물량 증가)
- 초록 ▼ : 매물이 줄어듦 (소진/거래)

표의 **증감 숫자(▲▼)를 클릭**하면 어떤 매물이 변동했는지 목록이 뜹니다.
- 🔴 새로 올라온 매물 / 🟢 사라진 매물 (가격·층·면적·중개사 표시, 클릭 시 네이버로 이동)
- 매물 단위 비교는 **2일치 기록이 필요**해, 첫날은 현재 목록만 보이고 다음 날부터 증감이 표시됩니다.

## 다른 단지로 바꾸기

1. **new.land.naver.com** 에서 단지 검색 → 주소창의 `/complexes/`**`숫자`** 확인
2. 사이트 상단 "네이버 단지 번호" 칸에 입력 → **저장** → **갱신**

## 평형 표기 안내

평형은 네이버 표기와 동일하게 **공급면적 ÷ 3.3058** 로 계산합니다.
예) 동탄역포레너스 전용 84㎡(국민평형)은 공급 110㎡ → **네이버 표기 "33평"**.
혼동을 막기 위해 표에 **전용면적(㎡)** 도 함께 보여줍니다.

## 데이터 저장 위치

- `history.json` : 날짜별 평형별 매물 수 (자동 생성/갱신)
- `config.json` : 단지 번호 / 이름

## 잘 안 될 때

- "매매 매물이 0건…" → 단지 번호 확인.
- 수집이 실패하면 잠시 후 다시 시도하세요(네이버 일시적 요청 제한).

## 부팅(로그인) 시 자동 실행

`start-hidden.vbs` 가 서버를 **창 없이** 띄웁니다. 이 파일이 시작프로그램 폴더에
등록되어 있어, **PC 로그인 시 자동으로 서버가 실행**됩니다.

- 등록 위치: `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\매물추적기.vbs`
- **끄기/해제**: 위 폴더의 `매물추적기.vbs` 삭제 (탐색기 주소창에 `shell:startup` 입력하면 폴더가 열림)
- **지금 수동 실행**: `start-hidden.vbs` 더블클릭 (창 없이 실행됨)
- 실행 중인 서버 종료: 작업 관리자에서 `node.exe` 종료

> 서버가 켜져 있으면 **30분마다** 자동으로 수집해 공개 페이지에 다시 게시합니다(같은 날은 최신 값으로 덮어씀).

**자동 복구**
- `start-hidden.vbs` 는 꺼진 것만 띄우므로 여러 번 실행해도 안전합니다.
- `register-watchdog.ps1` 을 한 번 실행하면 작업 스케줄러("매물추적기 감시")가 **10분마다** 런처를 실행해
  서버·터널이 꺼져 있으면 되살립니다.
- `tunnel.js` 는 5분마다 터널 주소를 점검해 3번 연속 닿지 않으면 새 터널을 받아 재게시합니다.
- 수집 중 Playwright 브라우저가 없으면 자동으로 다시 설치합니다.
- PC가 **꺼져 있거나 절전** 중이면 동작하지 않습니다.
> 브라우저에서 http://localhost:5173 로 언제든 확인하세요.


## 공개 페이지에서 수동 수집

GitHub Pages 공개 페이지의 **"📥 지금 수동 수집"** 버튼은 Cloudflare 터널을 거쳐
이 PC 서버에 수집을 요청합니다(PC 서버와 `tunnel.js`가 켜져 있어야 함).

- `tunnel.js` 는 `cloudflared`(winget `Cloudflare.cloudflared`)로 계정 없는 Quick Tunnel을 엽니다.
  주소가 실행할 때마다 바뀌므로 새 주소를 `tunnel-url.txt` 에 적고 공개 페이지를 자동 재게시합니다.
- 외부 요청은 **10분에 1회**로 제한됩니다(네이버 요청 제한 방지).
- 공개 페이지에서는 **비밀번호**가 필요합니다. 비밀번호는 저장소에 올라가지 않는 `secret.json` 의 `refreshPassword` 에 둡니다. 5번 틀리면 15분간 막힙니다.
- 고정 주소를 쓰려면 `config.json` 에 `"publicUrl": "https://..."` 를 넣으세요.

## 개선·문의

화면 왼쪽 메뉴 **개선·문의** 에서 쓴 글은 **어디에도 저장하지 않고** PC 서버가 Gmail 로 관리자에게 메일만 보냅니다
(공개 페이지에서는 수동 수집처럼 터널을 거칩니다 — PC 서버가 켜져 있어야 함). 이미지·파일은 최대 5개, 합계 8MB까지 첨부됩니다.

메일 설정은 저장소에 올라가지 않는 `mail.json` 에 둡니다(.gitignore 처리됨).

```json
{ "user": "보내는주소@gmail.com", "pass": "Gmail 앱 비밀번호 16자리", "to": "받는 주소" }
```

- 앱 비밀번호: Google 계정 → 보안 → 2단계 인증 켜기 → "앱 비밀번호" 생성.
- 파일을 저장하면 바로 적용됩니다(서버 재시작 불필요).
- 보내는 Gmail 의 "보낸편지함" 에는 사본이 남습니다.

## 구성 파일

- `server.js` : 웹 서버 + 스냅샷 저장/비교
- `naver.js` : 브라우저 창을 띄워 매매 매물 수집(Playwright)
- `index.html` / `style.css` / `app.js` : 화면

> 데이터 출처: 네이버 부동산(비공식). 개인 참고용으로만 사용하세요.
